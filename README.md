# itowa 管理画面 サンプル（注文管理＋名札作成）

葬儀社様にご覧いただくための静的サンプルです。実際のデータは保存されません。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ホーム・葬家管理・注文管理・配信機能・利用状況 |
| `name-tag.html` | 名札作成・利用状況（名札生成数） |

2つのファイルは同じ階層に置いてください。サイドメニューで行き来します。

## GitHub Pages で公開する

リポジトリの直下にこの2ファイルを置き、Settings → Pages で
Source を `Deploy from a branch`、Branch を `main / (root)` に設定してください。

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

`index.html` が入口になります。

## サイドメニュー

両方のファイルで、項目・並び・アイコンを揃えてあります。

```
ホーム ／ 葬家管理 ／ 注文管理 ／ 利用状況 ／ 名札作成 ／ 配信機能 ／
業者管理 ／ 商品管理 ／ 返礼品管理 ／ スケジュール管理 ／
担当者別葬儀履歴 ／ 月別累計売上高 ／ 操作ログ ／ 設定
```

いま開いているファイルに無い画面を押すと、もう一方に切り替わります。
見た目が同じなので、ひとつの管理画面の中を移動しているように見えます。

## 3つの画面の紐付け

```
葬家一覧（葬家管理）
  ├ 行の「注文管理」 → その葬家の注文リストへ
  └ 行の「名札作成」 → その葬家の名札リストへ

注文リスト
  └ 上部の「名札作成」 → 同じ葬家の名札リストへ

名札リスト
  └ 上部の「注文管理で見る」 → 同じ葬家の注文リストへ
```

葬家名・会場・通夜・葬儀の日時が引き継がれます。
注文管理から渡ってきた葬家には「注文管理から」の印が付きます。

## 機能権限の切り替え

画面上部の「機能権限」で、管理者・担当者・業者名札作成を切り替えられます。

**業者名札作成** を選ぶと、サイドメニューが名札作成と利用状況だけになります。
葬家一覧から喪主の列も消えます。業者に何が見えるかの確認にお使いください。

## 名札作成でできること

- 葬家一覧 → 名札リスト → 商品と数量 → 名札入力 → 微調整 → 出力
- 一括取り込み。テンプレートCSVは実際にダウンロードでき、記入して読み込ませられます
- 出力の「実寸で開いて印刷」で、195×495mm の実寸ページが新しいタブで開きます
- 各入力欄の「字が出ない」から外字を探せます（親字 → 異体字 → MJ番号）

## ご覧いただく順序

```
1. 葬家管理で一覧を見る
2. 行の「注文管理」を押し、その葬家の注文を見る
3. そのまま上部の「名札作成」を押す　← 同じ葬家のまま切り替わります
4. 商品と数量 → 名札入力 → 微調整
5. 出力 →「実寸で開いて印刷」で用紙サイズを確認
```
